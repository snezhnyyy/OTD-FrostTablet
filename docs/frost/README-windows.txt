EN
1. Close other tablet drivers (OpenTabletDriver in the tray, Wacom/Huion/XP-Pen drivers).
2. Run FrostTablet.exe. Interface and driver are in this one file; nothing else to install.
   SmartScreen warning? "More info" -> "Run anyway" (the app is not code-signed yet).
3. Your OpenTabletDriver settings and plugins are picked up automatically.
   Portable mode: create a folder "userdata" next to FrostTablet.exe.

RU
1. Закрой другие драйверы планшета (OpenTabletDriver в трее, драйверы Wacom/Huion/XP-Pen).
2. Запусти FrostTablet.exe. Интерфейс и драйвер — в этом одном файле, больше ничего ставить не нужно.
   Ругается SmartScreen? «Подробнее» -> «Выполнить в любом случае» (у программы пока нет подписи).
3. Настройки и плагины OpenTabletDriver подхватятся сами.
   Портативный режим: создай папку «userdata» рядом с FrostTablet.exe.

Язык и тема — внизу слева. Пресеты, плагины, отладчик — кнопка «…» справа вверху.
